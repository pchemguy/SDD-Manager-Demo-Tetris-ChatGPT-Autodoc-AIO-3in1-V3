# Milestone 9.1 — Shared sidebar sessions

## Capability and review

T-063 and T-064 provide the window-scoped session broker and extension-local settings/file ports. T-065 composes them with the existing C3 controller and compact C4 UI. Gameplay stays in the panel page; the background only serializes requests, owns writer generations and clears removed-window records. Persistent local storage contains only six settings. Session storage contains the versioned game, leaderboard and global generation counter. Browser restart ends those sessions; background restart preserves them.

Acquire validates complete state, replaces the writer lease and returns a paused game with unchanged remaining timers. Ordered revisions acknowledge completed storage writes. Commands checkpoint coherent states; timer-only writes are bounded to 100 ms. Storage failure pauses and retains explicit non-recovery feedback. The prior unacknowledged transition is not promised recoverable. Reopening never advances closed wall time. Dispose releases UI/input/lifecycle resources and the writer on a best-effort basis.
