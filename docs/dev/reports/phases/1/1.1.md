# Milestone 1.1 — Deterministic classic engine

## Result

Complete within the milestone scope: pinned local tools and isolated browser facilities, immutable piece geometry/ordinary landing, serializable uniform sequence and pure classic movement/gravity/grounded locking. T-001/T-002 are published; this report closes with T-003 and its initial checkbox. Browser gameplay UI, line clearing/scoring, modern rules and platform packages remain their later assigned tasks.

## Verification and review

- Toolchain: TypeScript 7.0.2, Vite 8.3.5, Vitest 5.0.5 and Playwright 1.64.1 on Node 24.22.1. T-001 records trusted browser provisioning and four successful isolated input/Canvas/font/screenshot/teardown cycles. No application acceptance is inferred from those probes.
- T-002 RED/GREEN: seven intended geometry failures against empty API stubs, followed by nine passing public geometry cases.
- T-003 RED/GREEN: eight intended engine failures, followed by initial 20-test full-suite success. Independent code review then found bounded-sampling bias; six fixed-seed cases failed before its correction. Final `npm run test:unit` passes 29/29; `npm run check` and `npm run build` pass.
- Contract checks cover spawn/idle, above-top/bounds/collisions, seed determinism/validation, ordinary landing, full grounding interval independent of the gravity phase, preserved deadlines on grounded moves/rotations, reset on lifting, pause preservation, equal-time lock precedence, leftover elapsed time across a spawn and safe exact-once top-out.
- Independent read-only reviewer inspected the complete C1/C2 candidate, tests and applicable milestone/SPEC scope. The focused recheck independently reran 29 tests and found no remaining blocker. Publication/issue/milestone closure are subsequent coordinator effects.

## Findings and recheck

M1.1-F01, medium: xorshift32 excludes zero, so a 2^32-based rejection domain left one residue underrepresented. Corrected the sampler to rebase each draw by one over cardinality 2^32-1, reject the non-divisible suffix and retain the raw generator state. Six independent inversion-derived fixed seeds cover accepted/modulo/rejected boundaries. All fail before the correction and pass afterward. Reviewer confirmed the arithmetic and resolution.

No other scoped implementation defect was identified. Scoring/clearing, controller/UI and modern behavior were explicitly excluded because the PLAN assigns them to later work; this is not a claim that the complete game is delivered.
